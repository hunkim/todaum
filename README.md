# ToDaum

네이버·언론사 뉴스 URL을 같은 다음 기사로 보냅니다. 없으면 원래 URL로 갑니다.

- `https://todaum.vercel.app/` — 붙여넣기
- `https://todaum.vercel.app/<뉴스 URL>`
- `https://todaum.vercel.app/?u=<뉴스 URL>`

ToDaum은 Daum·카카오와 무관한 개인 프로젝트입니다.
